# 问序问卷系统

## 项目简介

本项目基于 Vue、FastAPI 和 MongoDB，在第一阶段1.1.0问卷核心上扩展为第二阶段2.0.2，保留原问卷、跳转、校验、填写恢复与统计，新增常用题、题目版本、共享、题库和使用查询。用户还可以汇总同一题目版本在自己或获授权问卷中的回答。报告说明了为什么修改原设计、具体改了什么，以及怎样检查旧功能。

第一次运行先看代码README，操作页面时看系统说明。评阅时可以先读项目报告，需要核对细节再查设计文档和测试记录。
