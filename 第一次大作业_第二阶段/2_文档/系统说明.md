# 问序问卷系统第二阶段系统说明

应用版本：2.0.2。系统在第一阶段 1.1.0 的基础上继续扩展，保留原有问卷、跳转、填写恢复和统计功能，新增常用题、题目版本、共享、题库和跨问卷统计。

本说明面向使用者，介绍从哪里进入、怎样完成操作，以及操作结果代表什么。安装、配置和启动步骤见[代码 README](../1_代码/README.md)。

## 一、第一次使用从哪里开始

不同使用目的可以采用不同路线，不必一开始就了解所有功能。

| 使用目的 | 建议路线 |
|---|---|
| 创建一份普通问卷 | 创建问卷 → 添加题目 → 保存 → 发布 → 试填 → 查看统计 |
| 保存以后还会用到的题 | 创建常用题或从自有问卷保存 → 导入其他问卷 |
| 修改题目但保留旧内容 | 基于旧版创建新版 → 在问卷中预览并确认升级 |
| 整理个人题目 | 创建题库 → 加入确定版本 → 排序、更新或移除 |
| 把题目共享给别人 | 选择确定版本 → 授权指定账号 → 接收者导入 |
| 汇总多份问卷中的同一道题 | 选择确定版本 → 检查统计权限 → 设置筛选范围 |

系统需要登录。匿名填写表示向问卷创建者隐藏实名身份，不表示可以免登录使用。

本说明依据现有页面和接口整理。实际测试与尚未完成人工验收的范围，见[测试用例与结果](../3_测试用例/测试用例与结果.md)。

## 二、先分清几个概念

### 2.1 系统中的主要对象

| 概念 | 通俗解释 |
|---|---|
| 常用题／题目系列 | 独立保存的一道题，例如“年龄题” |
| 题目版本 | 这道题某次固定的内容，例如 v1、v2 |
| 问卷实例 | 常用题放进某份问卷后的具体一次使用 |
| 问卷发布版本 | 发布时保存的整份问卷内容，也叫发布快照 |
| 填写过程 | 尚未正式提交的输入和进度 |
| 正式答卷 | 完整检查通过后保存的一次提交 |

同一个年龄题 v1 可以放进两份问卷，形成两个实例。两份问卷分别设置必答和跳转，互不自动改变。

### 2.2 几个操作不是一回事

| 操作或状态 | 表示什么 | 不代表什么 |
|---|---|---|
| 保存问卷草稿 | 保存当前编辑内容 | 不等于发布，也不使独立截止时间设置生效 |
| 发布问卷 | 生成可供新填写使用的完整版本 | 不改写旧发布快照 |
| 保存填写进度 | 保存服务器确认的过程输入 | 不计入正式统计 |
| 更新题库成员 | 更换题库收录的版本 | 不自动升级已采用它的问卷 |
| 创建题目新版 | 保存一次新内容 | 不自动替换所有旧版 |
| 预览问卷 | 查看展示和基本配置 | 不代替发布后的实际分支试填 |

## 三、账号、角色与权限

同一账号可以同时拥有多种身份，例如既是题目作者，也是问卷创建者。

| 身份 | 可以做什么 | 主要边界 |
|---|---|---|
| 注册用户 | 创建问卷、常用题、个人题库，填写开放问卷 | 登录后仍不能任意读取他人数据 |
| 题目所有者 | 创建版本、比较、恢复、归档、共享指定版本 | 不因他人采用题目就获得对方答案 |
| 共享接收者 | 使用获授权版本，导入自有问卷或加入个人题库 | 不自动获得未来版本、修改和转授权限 |
| 问卷所有者 | 编辑、发布、关闭、查看自有问卷统计，授予相应汇总权限 | 不能授予别人的问卷数据权限 |
| 汇总授权接收者 | 查看指定范围、指定版本的汇总统计 | 不获得他人问卷详情或原始答案 |

前端按钮用于提示，后端仍会检查权限，不能通过自行调用接口绕过。

## 四、完成一份普通问卷

### 4.1 创建和编辑

1. 在“我的问卷”创建问卷，进入编辑器。
2. 填写标题和说明。
3. 添加单选、多选、文本或数字题。
4. 设置选项、输入限制和必答要求。
5. 按需配置跳转。

暂时不设置跳转时，按题目顺序填写。跳转只允许指向后续题或结束问卷，不能返回前题形成循环。

### 4.2 保存和发布

点击“保存草稿”同步编辑内容。草稿可以继续调整，不会立即改变已发布问卷。

截止时间在发布时提交，单独保存问卷草稿不能将它当作已经生效。设置完成后，点击“发布新版本”并确认；若发布被拒绝，先按提示修正题目、跳转或来源问题。

发布成功后，可通过“打开填写页”试填，或使用“复制填写链接”分享。实际跳转体验应在发布后的填写页检查。

### 4.3 填写、退出和恢复

填写者注册并登录后开始回答。页面会自动同步进度，但应留意保存状态：

| 页面状态 | 应怎样理解 |
|---|---|
| 有修改尚未保存 | 当前输入还没有全部得到服务器确认 |
| 已保存到服务器 | 对应修改已确认，可供后续恢复 |
| 保存未完成 | 留意错误提示，不要假定内容已经同步 |
| 只读 | 可以查看已有过程，但不能继续保存或新增提交 |

同账号再次进入时，可以恢复服务器已确认保存的过程。即使问卷后来发布新版，原过程仍按开始时的版本继续。

关闭或截止后，已有过程可以只读恢复。尚未同步的输入不能保证在直接关闭浏览器后恢复。

### 4.4 提交和统计

完成实际路径上的必答题后提交。后端会重新检查答案，页面到达末题不等于已经提交成功。

只有正式答卷计入统计，未提交的填写草稿不计入。重复提交同一过程不会生成第二份答卷；是否允许重新填写，则由问卷的重复填写设置决定。

## 五、创建、复用和更新常用题

### 5.1 创建常用题

进入“题目管理”并创建题目，填写题型、题干、选项、校验和修改说明，保存后生成 v1。

也可以在自己的问卷中将题目“保存为常用题”。保存的是题目内容，不复制原问卷专属的必答和跳转，也不自动关联过去的答案。

他人共享来源的实例不能通过这个入口另存成自己的题。

### 5.2 导入问卷

在问卷编辑器中：

1. 点击“从题库或共享题导入”。
2. 搜索题目或选择题库。
3. 选择确定版本。
4. 导入后检查必答、位置和跳转。

后端生成新的实例 ID，初始为必答，跳转规则为空。

导入后题干、题型、选项和校验只读，这是固定来源版本的正常表现。必答、顺序和跳转仍由当前问卷设置。

### 5.3 修改并升级

需要改题目内容时：

1. 在题目列表选择“基于此版修改”。
2. 编辑并保存，生成新版本。
3. 回到问卷编辑器，选中要升级的实例。
4. 点击“选择版本并预览升级”，选择同系列目标版本。
5. 核对差异和规则问题，确认升级草稿。
6. 修复问题后重新发布。

创建新版不会自动更新问卷，确认升级也只改变当前草稿。

预览后切题、改目标、继续编辑或关闭窗口，会使旧确认失效，需要重新预览。这个保护用于避免把 A 题的预览误用于 B 题。

### 5.4 比较与恢复历史

题目所有者可以进入历史页面，选择版本比较字段变化，或恢复历史内容。

恢复会新增版本，不删除新版，也不重新使用旧编号。例如在 v3 时恢复 v1，会产生一个记录恢复来源的新版本。

取消不创建版本；确认后不要重复操作。最近创建的版本不一定适合所有问卷，仍需明确选择。

### 5.5 归档和解除来源

归档保留历史，停止新增使用；原合法实例不因此被删除。

自有来源题可以通过专门操作解除关联，再作为普通题编辑。共享来源不能解除，也不能通过漏传来源字段实现相同效果。

## 六、共享与撤销授权

### 6.1 共享确定版本

题目所有者在指定版本下输入接收者用户名并授权。接收者在题目管理中看到获授权版本，可以导入自有问卷或加入个人题库。

共享 v1 不包含未来的 v2，也不包含修改、派生、再共享或答卷访问权限。

首次使用授权从题目指定版本入口发起；“共享与授权”用于查看和管理已有记录。

### 6.2 撤销后的影响

| 对象或操作 | 撤销后 |
|---|---|
| 原合法导入的草稿实例 | 保留原版本，可以继续保存和发布 |
| 已发布快照及旧填写过程 | 继续按原内容使用 |
| 新增导入 | 重新检查当前授权，被撤销授权不能使用 |
| 替换为其他版本 | 检查目标版本的当前权限 |
| 复制旧来源到别处 | 不允许借此新增使用 |

归档也会限制新增使用。已有来源只属于原问卷和原实例，不是可以随意复制的永久许可。

## 七、创建和管理个人题库

进入“我的题库”，填写名称和说明并创建，再选择该库加入题目版本。

成员可以排序、更新和移除。同系列不同版本可以并存，同一个确定版本不能重复加入。

更新成员只改变题库记录，不修改任何已导入问卷。题库也不会为共享题增加转授权能力。

如果旧版授权撤销、新版仍有效，可以打开更新窗口选择新版；提交前新版也被撤销时，更新失败，原成员保留。

切换题库或成员会清除旧选择窗口，提交期间限制切换。选题窗口可继续加载后续题库，题库内搜索按有权读取的固定版本内容进行，并在分页前筛选。

## 八、查看使用情况和统计

### 8.1 查看题目被怎样使用

从题目列表进入“使用情况”，分别查看当前草稿、当前发布和历史发布。

这些分类可能重叠，“历史发布”包含当前发布。因此，同一问卷发布多次仍算一份使用问卷，不能把分类数字直接相加。

用户查看自己的问卷明细；题目所有者按权限查看外部脱敏数量，不直接看到他人的私密标题和内容。共享接收者使用独立入口，不必进入所有者历史页面。

### 8.2 查看单题跨问卷统计

选择确定版本进入统计，按需设置问卷和正式提交时间；数字题还可设置分组边界。

题目作者不会自动获得他人答案。需要汇总他人问卷时，由相应问卷所有者在编辑器中授予“此问卷、此版本”的汇总权限。

接收者可以从“共享与授权”的有效记录进入“查看授权统计”。只有统计授权时，题目使用列表可能为空，并不代表统计权限无效。

| 指标 | 含义 |
|---|---|
| 使用问卷数 | 草稿或发布历史中采用题目的问卷数 |
| 统计覆盖问卷数 | 有权限范围内发布使用过该版本的问卷数，包括零作答 |
| 有作答问卷数 | 筛选范围内实际有有效作答的问卷数 |
| 有效答卷数 | 不同正式答卷的数量 |
| 有效作答条数 | 匹配实例的答案数量，一份答卷可以贡献多条 |
| 多选比例 | 选项次数除以有效作答条数 |

例如，一份答卷中出现两个同版本实例，计为一份答卷、两条作答。多选比例总和也可以超过 100%。

时间筛选依据正式提交时间，包含起止端点。不同版本分别统计，不自动合并。

数字分组边界需要有限、安全且严格递增；分组采用左闭右开区间，范围外另计。跨问卷文本统计只提供条数，原文仍按原问卷权限查看。

### 8.3 查询结果与筛选条件

新日期未点击应用时，当前结果仍属于原范围。切换版本或重新查询后，只显示最新有效请求的结果。

查询失败时应查看错误提示，不能把旧数据当作当前查询成功。没有结果时，先核对版本、权限、提交时间和问卷范围，不应通过扩大权限绕过限制。

## 九、操作失败时怎样处理

| 提示或情况 | 含义 | 建议处理 |
|---|---|---|
| 修订冲突，通常为 409 | 其他页面已先修改 | 保留当前输入，核对服务器状态后处理 |
| 来源不一致，通常为 403 | 内容或来源不符合原记录 | 使用导入、升级或允许的解除操作 |
| 授权撤销或版本不可读 | 新使用不再被允许 | 请求相应所有者重新授权，或选择其他有效版本 |
| 题目已归档 | 停止新增使用 | 选择其他题；原合法实例可按规则继续使用 |
| 升级后规则失效 | 新内容与原跳转不匹配 | 保存待修复草稿，修复后再发布 |
| 登录过期 | 当前会话失效 | 保留页面，同账号重新登录后尝试同步 |
| 问卷关闭或截止 | 不允许继续写入 | 查看已有过程，不再保存或新增提交 |
| 统计无数据 | 可能是零作答或筛选、权限不匹配 | 核对版本、时间和范围 |
| 查询或保存失败 | 请求没有完成 | 查看提示后重试，不假定服务器已经保存 |

403、404、409 等状态码取决于具体接口。404 也可能用于隐藏无权访问资源的存在，不能只理解为数据一定不存在。

## 十、旧数据、功能范围与其他文档

旧题没有来源仍可正常使用。之后保存为常用题只影响当前草稿，不自动把过去答案合并进新系列统计。

本阶段未包含团队题库权限、共享题派生与转授、跨版本合并、历史人工关联、跨问卷去重人数、全文语义查重及公网部署。系统限制自身操作入口，不承诺阻止用户在外部手工重录相似题目。
