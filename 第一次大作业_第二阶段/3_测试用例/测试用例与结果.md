# 第二阶段测试用例与结果

应用版本2.0.2；测试材料补充修订2026-10-29。前面先说明当前测了什么、结果如何，后面给出步骤和原始记录。较早版本的结果放在附录，避免把新旧数量混在一起。

## 一 验证目标、方法和当前结论

测试主要检查前面承诺的几件事：来源不能伪造，旧问卷不被新修改影响，权限不能越界，失败不能留下半份数据，页面不能显示错对象或错版本。当前2.0.2共154后端+90组件+16逻辑=260项，2026-10-26结构统一包已再次通过；重复运行仍为260项。完整当前入口是[逐项索引](测试证据/逐项测试索引.json)。

不同测试负责不同问题。规则用单元测试检查，数据库结构和事务连接真实MongoDB验证，组件测试模拟输入和请求先后返回。最后再检查构建及压缩包能否独立使用。浏览器人工操作另列，不能用组件测试或旧截图代替。

## 二 前置条件与执行方法

1. 完成依赖安装并启动27019副本集。
2. 在代码根目录运行后端pytest；前端执行pnpm test；生产构建执行pnpm run build。
3. 后端fixture注册随机账号、创建问卷，使用服务器生成的动态ID和revision；另一账号由other fixture创建。
4. 每组按下列输入执行请求，核对HTTP状态、数据库和返回字段；具体完整载荷与断言以链接源码为准，不补造未留存的HTTP抓包。
