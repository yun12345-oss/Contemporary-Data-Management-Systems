# 问序问卷系统

## 项目简介

本项目基于 Vue、FastAPI 和 MongoDB，实现问卷创建与发布、单选/多选/文本/数字题、条件跳转、答案校验、填写进度保存与恢复，以及作答次数和去重人数统计。
